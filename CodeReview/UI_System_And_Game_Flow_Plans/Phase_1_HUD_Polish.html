Phase 1: In-Game HUD Polish

Objective

Upgrade the functional UI into a polished, readable, and responsive HUD during combat.

Key Tasks

  1. Health & Ammo Refinement:
  • Improve the styling of the health slider (e.g., color changing from green to red based on percentage).
  • Polish the reload UI (e.g., making it snap to the tank visually or stylize the slider).
  1. Wave Indicators:
  • Add a top-screen banner indicating the Current Wave number.
  • Add a progress bar or text element showing "Enemies Remaining" that updates via the WaveManager.
  1. Resource Counters:
  • Display the player's current currency/XP in a clean corner widget.
