# Phase 3: Visual Feedback & Animations

## Objective
Make the UI feel alive and responsive to player actions and game events.

## Key Tasks
1. **Damage Numbers:**
   * Implement floating text numbers that pop out of enemies when they are hit, varying in size for critical hits.
2. **Juice & Polish:**
   * Add small DOTween (or Unity Animator) effects to the UI, like the health bar vibrating when taking damage, or the currency icon popping when picking up a resource.
3. **Screen Shake hooks:**
   * Add subtle screen shake events on taking damage or firing heavy weapons to enhance combat feedback.
